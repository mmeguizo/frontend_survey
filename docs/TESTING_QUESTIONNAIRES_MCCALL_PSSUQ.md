# Testing Questionnaires: McCall's Quality Model and PSSUQ

**Project:** CHMSU Intelligent Service Request Monitoring and Analysis Platform  
**System:** ICT Support Ticketing System  
**Recommended Respondents:** 5 expert evaluators and 10 end users  
**Purpose:** Collect expert quality evaluation and user usability feedback after hands-on system testing.

---

## Part A. Testing Instructions

Before answering the questionnaire, ask each respondent to use the system with a test account and complete the applicable tasks.

### Suggested Test Tasks

| Task No. | Task |
| --- | --- |
| 1 | Log in using the assigned test account. |
| 2 | View the dashboard and check ticket status summaries. |
| 3 | Submit either an MIS or ITS ticket. |
| 4 | Use the AI ticket drafting or analysis feature, if available for the account. |
| 5 | Open My Tickets and review the submitted ticket details. |
| 6 | Track the ticket timeline, status, control number, and SLA information. |
| 7 | Use the knowledge base or documentation page to find support information. |
| 8 | For staff/admin roles, review, approve, assign, update, or resolve a ticket. |
| 9 | For resolved tickets, answer the satisfaction survey. |
| 10 | Record any errors, delays, confusing steps, or missing information. |

### Rating Scale

Use the same scale for both questionnaires unless otherwise stated.

| Rating | Interpretation |
| --- | --- |
| 5 | Strongly Agree / Excellent |
| 4 | Agree / Good |
| 3 | Neutral / Fair |
| 2 | Disagree / Poor |
| 1 | Strongly Disagree / Very Poor |

### Recommended Computation

1. Add all item ratings under each factor or subscale.
2. Divide the total by the number of answered items.
3. Compute the grand mean for all experts and all users separately.
4. Summarize common comments and list the top issues to fix before final deployment.
